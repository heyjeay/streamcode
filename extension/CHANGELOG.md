## 1.6.0

First Marketplace release.

- Live, syntax-highlighted mirror of the active editor for OBS / Meld browser sources.
- Twelve themes, a 3D stage (tilt, turn, rotate, perspective, depth, float), edge fade.
- Zoom on the code you point at or type: camera or lens.
- Every option is a VS Code setting; a gallery page previews and applies them.
- Private files (`.env`, secrets, keys...) are never sent; a status-bar button pauses broadcasting.
- The local server only answers the overlay on this PC: other websites can't read your
  code or write to your stream.
